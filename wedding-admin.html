Panduan Import Tamu (CSV)

Untuk menambahkan puluhan hingga ratusan tamu sekaligus, unggah file berformat .CSV.

Aturan Susunan Kolom:
  • Kolom A: Nama Tamu / Pasangan (Wajib)
  • Kolom B: Nomor WhatsApp (Opsional)
Contoh Susunan di Excel / Google Sheets:
Kolom A (Nama) Kolom B (WhatsApp)
Budi & Sarah 081234567890
Kiki & Pasangan (Kosong)
Cara Simpan dari Excel:
  1. Isi data nama & nomor WhatsApp sesuai kolom.
  2. Pilih menu File > Save As / Download.
  3. Pilih format CSV (Comma delimited) (*.csv).
